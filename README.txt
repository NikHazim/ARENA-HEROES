ARENA HEROES - NH TRADE EMPIRE
Cara main:
1. Upload index.html ke root repository GitHub.
2. Pastikan nama fail tepat: index.html
3. GitHub repository > Settings > Pages.
4. Deploy from a branch > pilih main dan /(root) > Save.
5. Buka URL GitHub Pages yang diberikan.

Game ini ialah prototaip browser satu pemain. Kemajuan disimpan dalam localStorage pada peranti/browser yang digunakan. Tiada backend, akaun online, multiplayer atau leaderboard global. Nombor telefon tidak dihantar atau dipaparkan; medan telefon hanya untuk aliran masuk dan tidak diperlukan untuk bermain.
Hero Rider Nova dan Titan Cahaya ialah watak original berkonsep adiwira bertopeng dan gergasi cahaya, bukan watak rasmi Kamen Rider atau Ultraman.
